# VisionDrill 자습서 구성안 v2

## 1. 원칙

- 문제풀이와 독립된 읽을거리. 문항에 맞춰 쓰지 않고, 개념을 처음부터 이어서 설명하는 한 편의 글로 씀
- 읽지 않아도 문제를 풀 수 있고, 풀지 않아도 읽을 수 있음. 해금·진도 조건 없음
- 대상은 원격탐사·GIS 회사의 비전 신입·비전공자. 수식은 최소한으로, 나오면 말로 한 번 더 풀어 씀
- 문체는 음슴체(~음, ~함, ~임). 존댓말·'~다.' 평서문은 쓰지 않음
- 목표는 "지시를 듣고 할 일을 아는 상태". 모든 강에 실무 지시문 해석 코너를 둠
- 범위 점검용으로만 문제은행의 장(63개)과 대응시킴. 자습서가 문항을 참조하지는 않음

## 2. 전체 구조

두 갈래로 나뉘고 마지막에 합쳐짐. 두 갈래는 어느 쪽부터 읽어도 됨.

```
0부 시작하기
 ├─ 통계·ML 갈래:  1부 통계 → 2부 회귀·진단 → 3부 ML 기본기 ─┐
 └─ 영상·DL 갈래:  4부 영상·기하 → 5부 딥러닝 → 6부 태스크·지표 → 7부 학습 실무 ─┤
                                                                  8부 모델 진단 (Diagnostics)
부록: 지시문 읽는 법 · 헷갈리는 용어 쌍 · 수식·기호표 · Diagnostics 용어를 밖에서 말할 때
```

| 부 | 강 수 | 대응 트랙 | 문항 |
|---|---|---|---|
| 0 시작하기 | 1 | (F.task 일부) | - |
| 1 데이터를 숫자로 읽기 | 5 | A | 89 |
| 2 관계를 모형으로 | 7 | B | 139 |
| 3 머신러닝의 기본기 | 7 | C | 133 |
| 4 영상과 기하 | 7 | D | 141 |
| 5 딥러닝 | 7 | E | 166 |
| 6 태스크와 평가 | 9 | F | 157 |
| 7 학습 실무 | 8 | G | 149 |
| 8 모델 진단 | 11 | H | 230 |
| 부록 | 4 | - | - |
| **합계** | **62강 + 부록 4** | | **1,204** |

분량: 강당 3,000~4,000자(읽는 데 10~15분). 전체 약 22만 자, 책으로 200쪽 안팎.

## 3. 강의 틀 (모든 강 공통)

1. **이 강에서 얻는 것**: 학습 목표 3개
2. **본문**: 절 3~5개. 개념 → 왜 필요한가 → 어떻게 계산·판단하는가 순
3. **현장에서는**: 원격탐사 2차 산출물·GIS 모델링 장면 하나 (4절)
4. **헷갈리는 쌍**: 이 강 개념과 자주 섞이는 개념 1~3쌍 (예: 정밀도↔재현율, 정사보정↔대기보정)
5. **이렇게 지시받음**: 실무 지시문 2~3개와 해석 ("mAP50은 높은데 50-95가 낮아" → 박스 위치 정밀도 문제)
6. **요약**: 5줄
7. **핵심 용어**: 이 강에서 처음 나온 용어 목록 (영문·한글·약어)

그림은 SVG로 그림. 강당 1~3개, 전체 약 90개 예상.

## 4. 사례 소재

가상 과제 하나로 책 전체를 관통시키지 않고, 강마다 알맞은 **원격탐사 2차 산출물**을 예로 듦. 중간중간 **GIS 모델링** 사례도 섞음. 실제 과제명·발주처·실제 수치는 쓰지 않음.

- 2차 산출물 예: 토지피복도, 식생지수(NDVI 등) 지도, 지표면온도(LST) 지도, 수계·해안선 지도, 변화탐지도, 수치표고모델(DEM·DSM)과 경사도, 건물·도로 벡터, 탐지 결과 폴리곤(시설물·선박·양식장), 해색 산출물(클로로필·탁도)
- GIS 모델링 예: 구역 통계(zonal statistics), 공간 보간(IDW·크리깅), 중첩·적지 분석, 버퍼·근접 분석, 래스터 대수, 공간 회귀(GWR), 핫스팟 분석(LISA)
- 강별 배치 예
  - 1부: 구역 통계로 요약한 NDVI·LST, 표본 기반 정확도 평가, 공간 자기상관
  - 2부: 지표면온도와 불투수면 비율의 회귀, 공간 회귀로 넘어가는 이유
  - 3부: 토지피복 분류와 정확도 평가, 공간 교차검증
  - 4부: 정사영상·DEM 제작 과정, 좌표계 변환, 밴드 합성
  - 5~6부: 건물·선박·시설물 탐지와 분할, 변화탐지
  - 7부: 타일 데이터셋 구축, 추론 결과의 벡터화와 GIS 연계
  - 8부: 산출물 품질이 특정 조건(구름, 입사각, 계절)에서 떨어질 때의 진단

## 5. 강 목록

표기: 강 번호 · 제목 — 다루는 내용 (대응 장)

### 0부 시작하기
- **0강 비전 모델 개발 한 바퀴** — 데이터 수집 → 라벨링 → 학습 → 평가 → 진단 → 배포의 흐름, 태스크 종류(분류·탐지·분할·변화탐지), 이 책을 읽는 순서 (F.task 일부)

### 1부 데이터를 숫자로 읽기 (통계 기초)
- **1강 요약통계와 이상치** — 평균·중앙값·최빈값, 표준편차·IQR·MAD, 왜도·첨도, 이상치를 찾는 기준과 로버스트 통계 (A.desc)
- **2강 확률분포** — 셀 수 있는 것(이항·포아송)과 잴 수 있는 것(정규·균등), 기댓값, 독립, 중심극한정리 (A.prob)
- **3강 표본에서 모집단으로** — 표본오차·표준오차, 점추정과 신뢰구간, 부트스트랩, 정확도 평가 표본 설계 (A.est)
- **4강 차이가 진짜인가** — 귀무가설·p값·유의수준, 1·2종 오류와 검정력, t검정·효과크기, 여러 번 검정할 때의 함정(FWER·FDR, 본페로니·홀름·BH), p-해킹 (A.test, A.mult)
- **5강 함께 움직이는 변수** — 공분산·피어슨·스피어만, 교란변수와 허위 상관, 공간 자기상관(Moran's I, LISA) (A.corr)

### 2부 관계를 모형으로 (회귀분석과 회귀진단)
- **6강 최소제곱 회귀** — 회귀계수·절편 해석, SST=SSR+SSE, R²와 수정 R² (B.ols)
- **7강 잔차로 가정 점검하기** — LINE 가정, 잔차 플롯 읽기, 이분산(브로이시-페이건)과 정규성(샤피로-윌크), 스튜던트화 잔차, WLS·강건 표준오차 (B.res)
- **8강 말썽꾸러기 변수와 관측치** — 다중공선성(VIF·조건수, 밴드 간 상관), 레버리지·Cook's D·DFFITS·DFBETAS, 로버스트 회귀 (B.vif, B.inf)
- **9강 시간과 공간이 얽힌 데이터** — 잔차 자기상관, Durbin-Watson, GLS·Newey-West, 시차 변수, 공간 자료에서의 주의점 (B.dw)
- **10강 변수 다듬기** — 로그·Box-Cox 변환, 표준화·정규화, 상호작용항, 다항 회귀, 더미 변수와 함정 (B.trf)
- **11강 규제와 모형 선택** — Ridge·Lasso·Elastic Net, 수축과 규제 강도, 1-SE 규칙, AIC·BIC, 단계적 선택, 간결성 원칙 (B.reg, B.sel)
- **12강 확률을 예측하는 회귀** — 오즈·로짓·시그모이드, 최대우도추정, 오즈비 해석, 결정 경계, 로그 손실, 다항 로지스틱 → 딥러닝 분류기로 이어지는 다리 (B.log)

### 3부 머신러닝의 기본기
- **13강 학습이란 무엇인가** — 지도·비지도·자기지도·준지도, 레이블, 손실함수, 모델 용량, 일반화, 추론 (C.base)
- **14강 과적합과 편향-분산** — 과적합·과소적합, 편향-분산 분해와 줄일 수 없는 오차, 학습곡선 읽기, 규제 (C.bv)
- **15강 제대로 검증하기** — 학습·검증·시험 세트, k겹·층화 분할, 데이터 누수, 공간 자기상관 때문에 부풀려지는 점수와 공간 교차검증, 시간 분할 (C.cv)
- **16강 트리와 앙상블** — 결정트리(지니·엔트로피·가지치기), 배깅·랜덤 포레스트·OOB, 그래디언트 부스팅, 특징 중요도의 함정 (C.tree)
- **17강 분류 성능 재기** — 혼동행렬, 정확도·F1·특이도, ROC-AUC, 매크로 평균, 원격탐사 정확도 평가(생산자·사용자 정확도, 카파) (C.met)
- **18강 한쪽으로 쏠린 데이터** — 클래스 불균형, 가중 손실·포컬 로스, 오버·언더샘플링·SMOTE, PR-AUC (C.imb)
- **19강 정답 없이 구조 찾기** — K-평균·ISODATA·계층·DBSCAN, PCA와 설명분산, t-SNE·UMAP 시각화 해석 (C.uns)

### 4부 영상과 기하 (고전 CV·원격탐사 기초)
- **20강 디지털 영상과 네 가지 해상도** — 픽셀·래스터·밴드, 공간(GSD)·분광·방사·시간해상도, 비트심도와 DN (D.pix)
- **21강 색과 밴드 조합** — RGB·HSV·Lab, 그레이스케일·감마, 트루컬러·폴스컬러 합성, 히스토그램 스트레칭 (D.col)
- **22강 필터** — 합성곱의 원리, 평균·가우시안·미디언, 샤프닝, 공간 주파수, SAR 스페클과 Lee 필터 (D.filt)
- **23강 이진화와 형태학 후처리** — 오츠 이진화, 침식·팽창·열림·닫힘, 연결요소, 구멍 메우기, 골격화, 수계 마스크 정리 (D.mor)
- **24강 특징점과 영상 정합** — 소벨·캐니, 해리스 코너, SIFT·ORB 기술자, 매칭과 RANSAC (D.feat)
- **25강 좌표와 기하변환** — 어파인·호모그래피, 리샘플링(최근접·쌍선형·큐빅)과 선택 기준, 좌표계와 재투영(EPSG), 정사보정 (D.geo)
- **26강 센서 모델과 입체시** — 핀홀 모델, 내부·외부 파라미터, 렌즈 왜곡과 캘리브레이션, 푸시브룸·RPC·GCP, 스테레오 기선·시차·에피폴라, DSM·DTM·DEM (D.cam, D.str)

### 5부 딥러닝
- **27강 신경망의 뼈대** — 퍼셉트론, 은닉층, 활성화 함수(ReLU·Leaky·GELU), 로짓과 소프트맥스, 보편 근사 정리 (E.nn)
- **28강 손실과 최적화** — 교차 엔트로피·MSE, 역전파, SGD·모멘텀·Adam·AdamW, 기울기 소실·클리핑, 에폭 (E.opt)
- **29강 학습을 안정시키는 장치** — 배치·레이어·그룹 정규화, 드롭아웃, 가중치 감쇠, 조기 종료, 라벨 스무딩, 학습·추론 모드 차이 (E.reg)
- **30강 합성곱 신경망의 부품** — 합성곱 층·커널·스트라이드·패딩, 출력 크기·파라미터 수 계산, 수용영역, 풀링, 1×1·팽창·깊이별 분리 합성곱 (E.cnn)
- **31강 백본의 계보** — VGG → ResNet(잔차 연결) → DenseNet → EfficientNet·MobileNet → ConvNeXt, 사전학습 가중치 (E.bb)
- **32강 어텐션과 비전 트랜스포머** — 셀프·멀티헤드 어텐션, 위치 인코딩, ViT·패치 임베딩, Swin, 귀납 편향과 연산 복잡도 (E.att)
- **33강 탐지·분할 모델의 구조** — 백본·넥·헤드, FPN, 1단계·2단계 탐지기, DETR, U-Net, Mask R-CNN, SegFormer (E.det)

### 6부 태스크와 평가
- **34강 비전 태스크 지도** — 분류·탐지·의미/인스턴스/파놉틱 분할·변화탐지·추적, 출력 형태와 대표 지표 (F.task)
- **35강 박스를 비교하는 법** — IoU, GIoU·DIoU·CIoU, 마스크 IoU, 소형 객체에서 IoU가 민감한 이유 (F.iou)
- **36강 정답 박스 배정** — 앵커 박스, 앵커 프리, IoU 기반 할당, SimOTA·TAL (F.anc)
- **37강 NMS와 대형 영상 후처리** — NMS와 IoU 임계값, 클래스 무관 NMS, Soft-NMS·WBF, 슬라이스(타일) 추론, NMS 프리 탐지 (F.nms)
- **38강 정밀도·재현율과 운영점** — TP·FP·FN, PR 곡선, F1, 운영점 고르기, 이미지당 오탐 수 (F.pr)
- **39강 mAP 읽는 법** — AP와 보간, mAP50 vs mAP50-95, COCO 프로토콜(maxDets, 크기별 AP), 원격탐사에서 크기 구간이 어긋나는 문제 (F.map)
- **40강 분할 지표** — 픽셀 정확도, mIoU, Dice, 경계 F1, 마스크 AP, 카파 (F.seg)
- **41강 회전 박스** — HBB와 OBB, 5·8파라미터 표현, 각도 규약과 경계 불연속, 회전 IoU, DOTA (F.obb)
- **42강 다중 객체 추적** — 칼만 필터·헝가리안 매칭, DeepSORT·ByteTrack, ID 스위치, MOTA·IDF1·HOTA (F.mot)

### 7부 학습 실무
- **43강 데이터셋 만들기** — 장면 단위 분할, 지리적 누수와 공간 완충 구역, 타일링과 중첩 크기 정하기, 배경 타일 (G.data)
- **44강 라벨링과 라벨 품질** — YOLO·COCO·VOC·GeoJSON 형식과 좌표 변환, 라벨링 가이드, 라벨 노이즈·누락, 검수 (G.lbl)
- **45강 데이터 증강** — 기하·광학 증강, 원격탐사에서 되는 것과 안 되는 것(회전, 분광 왜곡), 모자이크·믹스업·복사-붙여넣기 (G.aug)
- **46강 학습률과 스케줄** — 학습률 탐색, 워밍업, 코사인·계단·원사이클, 배치 크기와 선형 스케일링 (G.lr)
- **47강 배치와 GPU 자원** — 배치·유효 배치, OOM 대응, 혼합 정밀도·bf16, 기울기 누적, 데이터로더, DDP (G.batch)

## 7. 형식, 배포, 깨짐 방지

**원본**
- `content/lessons/<강번호>.md` (예: `01.md`, 부록은 `A.md`). 머리말: id, part, title, chapters(범위 점검용), version, updated, status
- 0강은 `00.md`(id: 00, part: 0). 부록은 part 9이고 강의 틀(3절)을 따르지 않음: 첫 절만 `## 이 부록의 쓰임`으로 정하고 나머지 구성은 자유(lint도 부록은 이 규칙으로 점검)
- 부록 B는 손으로 쓰지 않고 `content/lessons/fig-src/B.py`가 각 강의 "헷갈리는 쌍" 절을 모아 다시 만듦. 강 원고를 고친 뒤 이 스크립트를 다시 돌림
- 부 목록: `content/lessons/parts.json`
- 그림: `content/lessons/fig/<강번호>-<이름>.svg`. 그림을 만드는 스크립트는 `content/lessons/fig-src/`에 함께 둠(다시 그릴 수 있게)
- 공통 예제 자료: `content/lessons/data/` (예: 2부 회귀 강들이 함께 쓰는 가상 80개 행정동 LST 자료 `part2_lst.csv`와 생성 스크립트). 여러 강이 같은 자료를 이어 쓰면 수치가 서로 맞고 흐름을 따라가기 쉬움

**수식 (KaTeX, 앱에 내장해 오프라인 동작)**
- 인라인 `$...$`, 블록 `$$...$$`
- 표 안에서는 `|` 대신 `\lvert`, `\rvert`, `\vert` (표 칸 구분자와 충돌)
- 본문에 달러 기호를 쓰지 않음 (수식 구분자와 충돌)
- 한글 조사가 바로 붙는 굵게(`**구역 통계(zonal statistics)**라고`)도 깨지지 않도록 렌더러에 한글 처리 확장을 넣음

**그림**
- 도식은 SVG. 색은 클래스(`s-*` 선, `f-*` 채움)로만 지정해 라이트·다크 모드 모두에서 보이게 함. 앱 밖(GitHub)에서도 기본색으로 보임
- `id` 속성 금지(한 화면의 여러 그림끼리 충돌), 크기는 viewBox로만
- 참고 사진·영상 캡처는 PNG·JPG·WebP, 800KB 이하, 캡션에 출처 표기
- 모든 그림에 캡션 필수

**자동 점검 (`npm run lint:lessons`, CI에서도 실행)**
- 머리말 누락, 필수 절 누락·순서
- 수식 문법 오류(KaTeX 엄격 모드), 렌더링 후 남은 `$`, 적용 안 된 `**`
- 없는 그림 참조, 쓰지 않는 그림, SVG 색 직접 지정·id·viewBox
- 음슴체가 아닌 어미, 분량(권장 3,000~5,000자), 대응 장 용어가 본문에 나오는지

**앱**
- "자습서" 메뉴: 부·강 목차, 본문, 이전·다음 강, 읽음 표시(학습 기록과 별개)
- 자습서는 문제 팩과 별개로 앱 빌드에 들어감

**집필**
- 1강부터 순서대로. 집필 → 독립 검증 → 사람 검수

## 8. 8부 기준값 서술 원칙

Diagnostics의 경험적 임계값은 단일 값 대신 **대략적 범위**로 쓰고, 기준을 낮추거나 높일 때의 차이와 위험을 함께 씀.
- 범위: 원문 간 값이 다르면 그 값들을 포함하는 범위 (예: NMS 과잉 억제 비율 대략 20~30%)
- 낮게 잡으면: 처방이 일찍·자주 나감. 문제를 빨리 잡지만 오경보와 불필요한 재학습 비용이 늘어남
- 높게 잡으면: 처방이 드물고 확실할 때만 나감. 실제 결함을 늦게 발견함
- 현장에서 정하는 법: 데이터 규모, 재학습 비용, 배포 주기에 따라 조정
- 처방 등급(P0/P1/P2)은 범위로 쓸 수 없으므로, 조치의 성격(재학습 필요 여부)으로 설명
- 방향·정의 오류 정리(2026-10-02 결정)
  - RDI: 04장 정의(클린 대비 성능 하락률, 낮을수록 강건)로 통일. 09장 배포 게이트의 'min RDI ≥ 0.60'은 'max RDI ≤ 0.40'(= 유지율 1 − RDI ≥ 0.60)으로 고쳐 씀
  - OFI: 점수 s_k는 NMS 전 헤드 로짓(시그모이드·소프트맥스 전 값) 기준. 0~1 신뢰도를 그대로 넣으면 상한이 낮게 묶인다는 점을 밝힘
  - 소형 표적: 넓이(화소²) 기준. EPS = 실제 넓이 / GSD² < 16(약 4×4)은 형상 인식 한계, 32² = 1,024 미만은 COCO 소형. 한 변으로 말할 때는 √넓이로 환산해 병기
- 처방 규칙 엔진의 임계 범위(2026-10-02, 51강·`run_part8.py`의 RULES): 라벨 누락 0.10~0.15, 치명적 취약 슬라이스 미탐률 0.50~0.70(원문 0.70, 낮은 끝은 자습서 설정), NMS 과잉 억제 0.20~0.30, 위치 오차 중심 위주 0.50~0.60(원문 0.60), CUR 0.20~0.25, max RDI 0.35~0.40, ECE 0.10~0.12. 배포 게이트(61강)는 ECE ≤ 0.08, max RDI ≤ 0.40
